# eu-amo-pdf

Ferramentas para manipulação de PDFs.

## Funcionalidades

- Mesclar vários PDFs em um
- Comprimir/reduzir tamanho de PDF
- Converter DOC para PDF

## Desenvolvimento

### Requisitos

- Python 3.11+
- Docker (opcional)

### Instalação

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

### Executar

```bash
flask run
```

Ou com Docker:

```bash
docker-compose up
```
